# D-033 요금 미확인 시세 소스는 기본 꺼짐 (토스 미국 실시간)

- 날짜: 2026-10-09 · 상태: 추천안 채택(자율) · 담당: pm-lead(결정), architect(설정 기본값), data-engineer(Q-020)
- 계기: 독립 QA 관문 보고서 [main 실전 경로 2026-10-09](../reviews/gates/main-realpath-2026-10-09.md) 과금 검사 P2·P3 실패

## 문제
- [사실] D-024는 토스를 국내·미국 실시간 2순위로 정했고, `autotrade-default.json`의 `market-data.priority` 기본값이 `["KIWOOM", "KIS", "TOSS"]`였다.
- [사실] 토스 미국 실시간 시세 요금은 공식 확인이 없다([시세 조사](../research/market-data-limits.md) 0장 1번, 5장 "토스 미국 실시간 시세 요금 `[추론]` 무료").
- [사실] 2026-10-09 재확인: 토스증권 공식 Open API 소개 페이지(`corp.tossinvest.com/ko/open-api`)와 출시 보도자료(`corp.tossinvest.com/ko/news-room/detail?id=52615`)는 스크립트로 그려지는 페이지라 이 환경에서 요금 문구를 읽지 못했다. 검색에 걸린 것은 개인 블로그 등 2차 자료뿐이다. 그래서 여전히 `[추론]`이다.
- 지침 8장 1번: 돈이 드는 선택은 사용자 결정이다. 요금을 모르는 소스가 기본으로 켜지면 사용자가 모르는 사이 과금될 수 있다.

## 결정
1. 요금이 공식 확인되지 않은 외부 소스는 **기본 설정에서 꺼 둔다**. 사용자가 설정에 직접 넣을 때만 쓴다.
2. `market-data.priority` 기본값을 `["KIWOOM", "KIS"]`로 바꾼다. 사용자가 `runtime-config.json`에 `TOSS`를 넣으면 D-024 순서(키움 1, 토스 2, 한국투자 3)로 쓴다.
3. 유료로 확인되면 사용자 결정 전까지 켜지 않는다. 무료로 공식 확인되면(Q-020) 이 결정을 새 번호로 되돌려 기본 목록에 다시 넣는다.
4. D-024의 순서·연결 배분 규칙은 그대로다. 이 결정은 "기본으로 켜지느냐"만 바꾼다.

## 대안 비교
| 대안 | 장점 | 단점 | 판단 |
|---|---|---|---|
| A. 기본 목록에서 빼기(채택) | 설정 키 추가 없음, 사용자가 넣기만 하면 원래대로. 과금 위험 0 | 기본 설정의 실시간 용량이 줄어듦(키움 200종목 + 한국투자 41건) | 채택 |
| B. `market-data.toss.enabled` 같은 새 스위치 키 | 의도가 이름에 드러남 | 키 하나 늘고 priority와 이중 관리. 열린 PR #10·#18이 같은 설정 파일을 고치고 있어 충돌 면적이 커짐 | 버림 |
| C. 그대로 두고 요금 확인만 기다림 | 변경 없음 | QA P3 실패가 남음. 요금 미확인 소스가 기본으로 켜짐 | 버림 |

## 영향과 남은 위험
- 기본 설정에서 토스 실시간 2순위가 빠지므로, 키움·한국투자 두 곳이 설정되면 D-009 SHARDED, 한 곳뿐이면 FAILOVER다. 한국투자 용량이 41건이라 키움 장애 시 감시 종목이 크게 준다 `[추론]`. 시세 2단계 실측에서 문제가 되면 Q-020 확인을 앞당긴다.
- 토스 보유 종목 보호 폴링(HELD_ONLY, 실전 엔진)은 실전 계좌가 토스일 때만 그 계좌 자격으로 쓰는 경로라 이 결정과 별개다. 그 요금도 Q-020에서 함께 확인한다. **보유 종목 보호 폴링은 결정 1의 예외다**: 기본 실전 계좌가 없어(`real-trading.accounts: []`) 기본 설정으로는 호출이 없고, 끄면 장애표 #2·#15의 보유 종목 보호가 약해진다. 이 폴링을 끄거나 유료 판정으로 막는 변경은 risk-ops 검토와 사용자 결정을 거친다(PR #21 risk-ops 검토 R-3).
- 알림: 카카오톡 나에게 보내기·Slack은 `notification.*.enabled=false` 기본이라 P3 조건(기본 꺼짐)을 이미 만족한다. 유료 알림톡(BIZ)은 쓰지 않는다(MON-06).
- 되돌릴 조건: 토스 공식 요금 문서나 약관에서 미국 실시간 무료가 확인될 때.
