## 결정

1. **결측이 이어지면 되풀이해 알린다**(QA R1): 필수 값(드라이브 경로별 여유, `cpu.system`, `memory.used`)이 빠지면 WARN을 남기고, 빠진 채 이어지면 `Watchdog.MISSING_REPEAT`(10분, 하트비트 설정 폴더 경고와 같은 간격, 설정 키 아님)마다 다시 남긴다. 이전에는 결측 집합이 바뀔 때만 남겨, 처음부터 CPU를 못 읽는 PC에서는 기동 직후 한 줄 뒤로 위험 판정이 꺼진 것이 로그에 보이지 않았다.
2. **오가는 결측은 간격마다 한 번**(QA R4): 같은 값이 점검마다 빠졌다 돌아오기를 되풀이해도, 마지막 경고 뒤 간격 안에서는 이미 경고한 값으로는 다시 WARN하지 않는다. 경고하지 않은 값이 새로 빠지면 간격과 상관없이 바로 알린다. 경고한 뒤 모두 돌아오면 INFO를 한 번 남기고, 그 뒤 경고 없이 오간 회복은 남기지 않는다. 그래서 오가는 결측은 간격마다 WARN 하나와 INFO 하나가 최대다.
3. **D-095 문구 정정**(QA R3): D-095 위험과 한계의 "`getCpuLoad`는 첫 호출이나 짧은 간격에서 음수(모름)를 줄 수 있다"는 JDK 21(이 저장소 빌드 JDK)에서 첫 호출이 `0.0`을 준 관측(QA J1)과 다르다. 첫 호출은 0(정상으로 판정)일 수 있고, 음수는 OS가 값을 주지 못하는 경우다 `[사실]`(근거: `docs/reviews/pr-122/qa.md` J1). 기본 연속 3회라 첫 0이 위험 판정을 늦추는 것은 한 주기이고, 해제는 정상 연속이 필요해 안전에는 영향이 없다. D-095는 머지된 결정이라 본문을 고치지 않고 이 결정으로 정정한다.
4. **Windows 값 대조**(QA R2): 감시 `memory.used`는 JDK `getFreeMemorySize`, 실험실은 OSHI 사용 가능 메모리라 같은 이름이라도 값이 다를 수 있다. 6단계 첫 운용일 확인 항목(`docs/runbooks/stage-6-live-session.md` 5장)에 감시 기동 로그의 CPU·메모리 값을 작업 관리자와 대조하는 항목을 넣는다.

## 대안

| 대안 | 판단 |
|---|---|
| ① 결측 지속 시 10분 반복 + 간격 안 같은 값 재경고 억제(채택) | 하트비트 설정 폴더 경고(PR #118 QA R1)와 같은 간격이라 운영자가 한 규칙으로 읽는다. 하루 결측이 이어져도 WARN 144줄 이하 |
| ② 기동 점검(`WatchdogMain.run`)에서 값을 한 번 읽어 결측이면 경고 | QA가 함께 권한 안. 그러나 이 JDK의 첫 `getCpuLoad`는 0이라 기동 때 결측을 잡지 못하고, 운영 중 깨지는 경우도 못 잡는다. 버림(①이 둘 다 덮음) |
| ③ 결측이 일정 시간 이어지면 기동 거부·정지 | 감시가 꺼지면 하트비트·드라이브 감시도 함께 꺼진다(D-095 위험). 버림 |
| ④ 지금처럼 집합이 바뀔 때만 | QA R1·R4 그대로 남는다. 버림 |

되돌릴 조건: 알림(MON-06)이 생기면 결측 지속을 알림으로 보내고 로그 간격은 그대로 둔다. 간격을 사용자가 바꿔야 하면 `watchdog.properties` 키로 올린다(지금은 하트비트 경고와 함께 코드 상수).

## 위험과 한계

- 간격 안에서는 같은 값이 다시 빠져도 로그가 없다. 마지막 로그가 회복 INFO인 채 다시 빠져 있을 수 있고, 다음 간격(최대 10분) 뒤 WARN으로 드러난다.
- 결측 경고는 로그뿐이다. 화면·알림 표시는 MON-06·ui-dev 후속(D-092 범위 밖 그대로).
- Windows에서 실제 값과 첫 호출 값은 확인하지 못함 `[추론]`. 4번 대조로 확인한다.

## 검증

- `WatchdogTest#값이_빠지면_바로_알리고_계속_빠지면_간격마다_다시_알린다`: 첫 결측 즉시, 간격 직전 없음, 간격에 다시, 새 값은 바로, 회복 INFO 한 번.
- `WatchdogTest#같은_값이_빠졌다_돌아오기를_되풀이해도_간격마다_한_번만_알린다`: 5분 동안 점검마다 오가도 WARN 1·INFO 1, 간격 뒤 다시 1, 두 값이 번갈아 빠져도 둘 다 한 번씩 뒤로는 조용함.
- 변이: 반복 조건 제거, 간격 안 경고 값 합치기 제거, 새 값 판정을 집합 동일 비교로, 회복 INFO 조건 제거를 각각 넣으면 시험이 실패한다.
