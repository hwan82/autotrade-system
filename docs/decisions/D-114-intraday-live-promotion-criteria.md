## 결정

장중 프로필의 8주 실시간 모의(EXP-20261026-LIVE01) 승격 후보 기준을 [6단계 계획](../strategy/stage-6-plan.md) 4.2의 L1~L11로 확정한다. 수치와 계산 방법은 그 표 그대로다.

1. L1~L5, L7~L9는 D-027 C1~C5, C7~C9 수치 그대로(비용 차감 수익률 > A01 기준선, PF ≥ 1.3, MDD ≤ 20%, 샤프 ≥ 1.0, 왕복 ≥ 30, ±20% 변형, 최고 1주 제외, 지연 2초).
2. L6은 C6 대체: 앞 4주·뒤 4주 각각 비용 차감 순손익 > 0.
3. L10은 본페로니 보정판: p = (k+1)/(N+1) ≤ 0.05/m, m = 6, N + 1 < 20m이면 판정 불가.
4. L11: 실시간 대 같은 날 녹화 리플레이 총수익률 차 ≤ 2%p, 체결 수 차 ≤ 10%.
5. 후보 = L1~L11 모두 통과. 후보 0개여도 기준을 낮추지 않는다.

## 범위
