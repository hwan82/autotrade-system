## 1. 목적과 범위

**목적**: 증권사 모의투자 API를 쓰지 않고, 실전 API로 받은 실시간 시세 위에서 자체 시드머니 모의 계좌 여러 개로 매매 기법을 병렬 운용·비교해 실전에 쓸 기법을 찾는다. 실전 매매는 검증을 통과한 기법에 한해 사용자가 UI에서 켤 때만 동작한다.

| 범위 | 포함 | 제외 |
|---|---|---|
| 시장 | 국내(KRX 코스피·코스닥), 미국 정규장(NYSE·NASDAQ·AMEX) | 미국 외 해외시장(D-014), 미국 프리·애프터·주간거래(D-015) |
| 증권사 | 토스·키움·한국투자, 설정되고 정상인 곳만(D-007) | 증권사 모의투자 API(D-003) |
| 매매 스타일 | 장중 단타, 일봉 스윙(D-006) | 파생상품, 소수점 매매(D-015) |
| 실행 환경 | 개인 PC(D-001) | 클라우드 서버 |

| ID | 요구사항 | 인수 조건 | 근거 |
|---|---|---|---|
| SIM-01 | 모의 단계에서 실전 API는 시세 수신에만 쓰고 주문 API는 호출하지 않는다. 모의 주문은 자체 가상 거래소에서 체결한다 | 모의 모드 전체 실행 중 증권사 주문 API 호출 0건(호출 계측 테스트로 증명) | D-003, team-design.md 2.2 |
| SIM-02 | 실험은 자체 시드머니로 시작한다 | 실험 설정에 시드머니가 기록되고 기본값은 D-021 | D-021 |
| SIM-03 | 매매 조건별로 여러 모의 계좌를 같은 시세 위에서 동시에 운용한다 | 한 실험에서 계좌 N개(N ≥ 2)가 같은 이벤트 스트림을 받아 독립 체결 | D-004 |
| SIM-04 | 기간을 정해 여러 매매 기법을 테스트한다 | 실험 = 기간 × 시드 × 전략 프로필 N개 × 비용 모델로 정의되어 저장 | team-design.md 3장 |
| SIM-05 | 결과를 비교해 실전 후보를 고른다 | 같은 실험의 계좌들이 리더보드로 비교되고 선발 기준(6장 STR-04) 통과 여부가 표시 | team-design.md 3장 |
