# D-066 중기(POSITION) 선발 기준 수치 확정 (Q-013 중기 부분)

- 날짜: 2026-10-12
- 상태: **사용자 결정**(BAE, 2026-10-12T14:08:16Z 프로젝트 스레드 "추천안대로 해주십시오."). strategy-researcher 추천안(D-057 [조합 실험 절차](../strategy/combination-experiments.md) 3장)을 그대로 채택
- 담당: strategy-researcher
- 근거: D-043 4번(중기 선발은 다년 일봉 워크포워드, 8주 실시간 모의는 무결성과 괴리 확인용), D-057, Q-013

## 결정

중기(`POSITION`) 조합의 선발과 8주 실시간 모의 통과 기준을 아래로 정한다. 승격 기준 변경분이라 사용자 결정이다.

1. **워크포워드 구간**: 학습 3년 + 검증 1년, 1년씩 굴림, 최소 3구간.
2. **검증 구간 최소 거래 수**: 구간 합 30건 이상. 못 미치면 판정하지 않는다(통과도 탈락도 아님).
3. **선발 판정**: `autotrade-strategy-lab` 스킬 5장 기준(비용 차감 후 벤치마크 초과, PF ≥ 1.3, MDD ≤ 20%, 검증/학습 ≥ 60%)을 검증 구간 전체에서 충족하고, 검증 구간의 3/4 이상에서 벤치마크를 넘는다.
4. **8주 실시간 모의와 백테스트 괴리**: 같은 8주를 일봉 리플레이로 다시 돌려 아래 셋을 모두 만족한다.
   - 진입 (종목, 거래일) 일치율 ≥ 90%
   - 체결가 괴리 평균 ≤ 0.5%
   - 누적 수익률 차이 ≤ 2%p
5. **8주 모의 무결성**: 주문 처리 오류 0건(STR-05 그대로).

## 범위

- Q-013의 **중기 부분만** 닫는다. 스타일별 KPI 전반, 장중(단타) 프로필 기준, D-027 C1~C10 확정은 녹화 데이터 실험 뒤 제안으로 Q-013에 남는다.
- RealTradingGuard, 블랙리스트, 리스크 한도, 실전 활성화 절차(7장)는 바꾸지 않는다. 이 수치는 승격 후보를 고르는 기준이고, 실전 활성화는 여전히 사용자 결정이다.

## 대안과 되돌릴 조건

대안 비교(구간 길이, 거래 수, 괴리 지표 순서)는 [조합 실험 절차](../strategy/combination-experiments.md) 3장 근거 열에 있다. 모든 수치는 실데이터 전 `[가정]`에서 출발했으므로 아래면 다시 제안한다.

- 실제 스냅샷으로 첫 워크포워드를 돌렸을 때 검증 구간이 3개 미만이거나, 대부분 조합이 30건에 못 미침
- 8주 모의에서 일치율은 높은데 수익률 차이만 2%p를 반복해서 넘음(비용·체결 모델 문제일 수 있어 sim-engine 확인 먼저)
