## 사용자가 본 선택지

| 선택지 | 결과 | 비고 |
|---|---|---|

## 결정

1. 블랙리스트(MANUAL)와 수동 보유(AUTO_ASSET) 종목은 의도와 상관없이 자동 주문을 막는다(`RiskChain` 1단계, D-032 결정 1.1 그대로). 지침 4장 3번 "어떤 경로로도 자동 매매되지 않는다"를 문자 그대로 따른다.
2. 이는 D-023 공통 원칙 1("손절·청산은 어떤 차단 규칙으로도 막지 않는다")의 **유일한 예외**다. D-023 본문은 결정 로그 규칙(기존 항목을 고치지 않음)에 따라 그대로 두고, 기획서 v13.1 7·8장 공통 원칙 1에 예외를 적었다.
3. 대신 시스템이 보유 중인 종목이 블랙리스트에 오르면 경고한다. MANUAL 지정은 등록 확인 화면에서, AUTO_ASSET 자동 등록은 긴급 알림으로 알린다(RSK-12, UI-05).

## 위험과 한계

- [추론] 경고를 놓치면 그 종목의 시스템 포지션은 손절 없이 남는다. 서버 측 손절(RSK-06)이 걸린 계좌는 증권사 쪽 손절이 계속 동작하지만, 미지원 계좌는 무방비다.
- 사용자가 다른 계좌에서 같은 종목을 직접 사면 AUTO_ASSET 자동 등록으로 이 상황이 생긴다(블랙리스트 전역 적용, RSK-12).

## 되돌릴 조건

경고 누락이나 무방비 포지션 사고가 1건이라도 나면 선택지 A(시스템 보유 수량 안의 청산 허용)를 다시 사용자에게 묻는다. 바꿀 때는 새 결정 번호로 기록한다.
