## 3. 워크포워드 판정 명령 명세 (sim-engine 구현용)

등록 파일 `experiments/<실험ID>/study.yaml`(사전 등록, 실행 전 커밋). 조합 실험 등록 파일(`CombinationPlan`)의 키에 아래를 더한다.

```yaml
id: "EXP-2026MMDD-WF01"
question: "..."
market: "KRX"
bars-snapshot: "krx-daily-..."
financials-snapshot: "dart-financials-..."   # 재무 선정이 없으면 생략
seed: "..."
seed-capital: "10000000"
parallelism: "4"
first-test-from: "2022-04-01"   # 첫 검증 구간 시작. 학습은 그 3년 전부터
train-years: "3"
test-years: "1"
windows: "4"                    # 3 이상(D-066)
warmup-days: "260"              # 각 구간 앞에 시세만 주고 진입은 막는 거래일 수
null-seeds: "400"               # 조합마다 무작위 대조군 시드 수. N ≥ m / 0.05 − 1 이어야 C10 판정 가능
combinations:                   # 후보(선정 x 전략)
  - "none x kr-ma-trend@1"
controls:                       # 스타일별 무작위 대조군 전략. 후보와 같은 선정으로 묶는다
  - "SWING kr-random-daily-swing@1"
  - "POSITION kr-random-daily-position@1"
```

실행 내용:

1. 구간 k마다 학습 `[t_k − 3년, t_k)`, 검증 `[t_k, t_k + 1년)`을 **새 계좌**로 돌린다. 같은 프로필을 그대로 쓰고 구간마다 파라미터를 고르지 않는다(프로필은 사전 등록). 학습 구간은 C6·C7 판단에만 쓴다.
   - **구간 끝 보유분**: 학습·검증 모두 구간 마지막 거래일 종가에 매도한 것으로 보고 비용(수수료·거래세·슬리피지)을 빼 `WINDOW_END` 왕복으로 넣는다. 그래서 PF·왕복 수·C10·자산 곡선이 같은 대상을 센다. 구간 안에서 상장폐지된 종목은 마지막 거래일 종가에 같은 방식으로 정리하고, 그 뒤 손실(정리매매 하락 등)은 데이터가 없어 반영하지 못한다는 한계를 결과 파일에 적는다. 구간 경계마다 현금화한다는 가정도 결과 파일에 적는다.
2. **예열**: 구간 시작 전 `warmup-days` 거래일의 시세를 전략에 주되 진입 신호는 버린다(이동평균·고가 계산용). 지금 실행기는 구간 밖 시세를 주지 않아 60일 평균 프로필은 1년 검증 구간의 약 1/4을 잃는다(`ScreeningCriteria.warmupDays` 주석). 예열 이벤트에는 체결·평가가 없어야 하고, 예열 시세가 학습 구간 끝을 넘어 검증 결과에 섞이지 않는지 테스트한다(미래 정보 금지).
3. **벤치마크**: 같은 스냅샷에서 계산한 시가총액 가중 지수(전일 원가격 종가 × 전일 상장주식수로 가중한, 권리 변동 수정 계수로 이은 수정 일수익률을 잇는 값, 비용 없음). 상장폐지 종목은 마지막 거래일까지 지수에 있고 그다음 날 빠진다(마지막 거래일 뒤 손실은 데이터가 없어 반영하지 못함). 수집기가 ETF·지수 시세를 받지 않으므로 KODEX 200 같은 ETF를 쓰려면 수집 범위를 넓혀야 해서 고르지 않았다. 동일가중 지수도 참고 열로 낸다.
4. **대조군 분포**: 조합마다 같은 선정 + 그 스타일 무작위 대조군을 `null-seeds`번(시드만 바꿔, i번째는 실험 시드 + i, i = 1..N) 각 검증 구간에서 돌린다. 판정은 경험적 p값 p = (k + 1) / (N + 1)(k = 후보 값 이상인 대조군 수, N = 완료된 대조군 수)이 0.05/m 이하일 때 통과(본페로니, 조합 실험 절차 1장 5번). 가장 작은 p인 1/(N + 1)이 0.05/m보다 크면(N < m/0.05 − 1) C10은 "판정 불가".
5. **±20%**: `study.key-param`을 ×0.8·×1.2로 바꾼 변형을 각 학습 구간에서(검증 구간을 보고 고치지 않음).
6. **비용 스트레스**: 슬리피지를 두 배(0.30%)로 한 검증 구간 실행. 일봉 경로는 다음 이벤트(다음 거래일 장 시작) 체결이라 주문 지연 2초(C9 원안)가 결과를 바꾸지 않으므로 대신 쓴다.
7. **결정론**: 전체를 병렬 수 1로 다시 돌려 판정표와 상세 보고서가 바이트까지 같은지.
8. 결과 파일: `results.md`(구간별·검증 전체 리더보드, 판정표), `runs.tsv`, `windows.tsv`, `inputs.yaml`, `detail.txt`. 실행 시각 같은 메타는 넣지 않는다.

검증 전체 지표: 구간별 검증 계좌의 일수익률을 이어 붙인 자산 곡선(구간마다 새 계좌라 수익률로 잇는다)과 모든 검증 구간 왕복의 합으로 계산한다.

## 4. 선발 기준 (일봉 워크포워드판)

D-066 3번(스킬 5장 전부 + 구간 3/4 이상 벤치마크 초과)을 C1~C10 틀(D-027)에 맞춘다. 모두 비용 차감 후다.

| 코드 | 기준 | 구간 |
|---|---|---|
| C1 | 시총 가중 지수 대비 초과수익 > 0 | 검증 전체 |
| C1w | 구간의 3/4 이상(3구간이면 모두)에서 지수 초과 | 구간별 검증 |
| C2 | Profit Factor ≥ 1.3 | 검증 전체 |
| C3 | MDD ≤ 20% | 검증 전체(이은 곡선) |
| C4 | 샤프 ≥ 1.0 | 검증 전체 |
| C5 | 왕복 ≥ 30. **못 미치면 이 조합은 "판정 불가"**(D-066 2번, 통과도 탈락도 아님) | 검증 합 |
| C6 | (모든 검증 구간 일수익률의 평균) ÷ (모든 학습 구간 일수익률의 평균) ≥ 0.6. 예열일은 빼고, 학습 평균이 0 이하면 탈락 | 검증 전체 / 학습 전체 |
| C7 | 핵심 파라미터 ±20% 변형이 원래 수익률의 50% 이상, PF ≥ 1.0 | 학습 |
| C8 | 가장 좋은 한 달을 빼도 수익(일봉 다년이라 주 대신 월) | 검증 전체 |
| C9d | 슬리피지 2배에서도 수익, PF ≥ 1.0 | 검증 전체 |
| C10 | 왕복당 순손익의 경험적 p값 (k + 1)/(N + 1) ≤ 0.05/m(3장 4번) | 검증 전체 |

C1w·C8·C9d·C10의 문턱 중 스킬 5장에 없는 값(50%, 1.0, 월 단위, 2배)은 D-027의 `[가정]`을 일봉에 옮긴 것이다. 판정 순서: C5 미달이면 다른 항목과 상관없이 "보류"(D-066 2번). 그 밖에는 탈락이 하나라도 있으면 "탈락", 판정 불가가 있으면 "보류", 모두 통과면 "통과". C6·C7의 학습 구간 값은 구간별 계좌의 일수익률을 모두 모아 평균한다(학습 구간끼리 겹치는 날은 구간마다 따로 센다).

**스윙 조합은 Q-051 답이 오기 전에는 판정표에 "통과"가 나와도 승격 후보로 넘기지 않는다.**

## 6. 위험과 한계

- **데이터 구간**: 재무 선정 백테스트는 2019년 4월부터라 첫 검증 구간이 2022-04다(D-066 근거). 가격만 쓰는 조합은 2013년부터 검증 구간을 더 둘 수 있지만 첫 실험은 재무 조합과 같은 구간으로 맞춘다(같은 기간끼리만 비교, 지침 5장).
- **세율 `[가정]`**: 2024년까지 세율은 법령 원문을 이 환경에서 열지 못해 2차 자료 여러 개로 맞췄다(D-071 표). 틀리면 그 해 매도 비용이 바뀌고 회전율이 높은 스윙 프로필이 더 크게 영향받는다. **판정 리포트를 단계 완료나 승격 근거로 쓰기 전에 law.go.kr 시행령 제5조 연혁과 대조한다**(D-071 7번). 대조 전 리포트의 결론에는 `[가정]`을 붙인다.
- **호가 단위**: 비용·체결의 호가 단위 표는 2023-01-25 시행분 하나뿐이라 그 전 기간의 반올림이 실제와 다를 수 있다. 일봉 경로는 시가 체결 + 고정 슬리피지라 영향은 작다 `[추론]`. 리포트에 적는다.
- **다중 비교**: m = 10이라도 같은 데이터에 여러 프로필을 대 보는 이상 우연히 좋아 보일 위험이 남는다. 리포트에 m과 시도한 등록 실험 수를 모두 적는다.
- **일봉 체결 모델**: `DAILY-PATH-V1`은 다음 날 시가 + 고정 슬리피지로 체결한다. 소형주 시가 체결은 이보다 불리할 수 있어 C9d(슬리피지 2배)로 버티는지 본다.
- **수집 미완**: 사용자 PC 수집이 끝나야 실험한다. 그전 결과는 합성 시세 파이프라인 검증뿐이다.
