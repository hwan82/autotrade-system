# D-025 3단계 실험실 MVP의 체결·비용·지표 기본 규칙

- 날짜: 2026-10-08
- 상태: 확정, **추천안 채택(자율)** (project-instructions.md 8장). 실전 경로·리스크 한도와 무관한 시뮬레이션 규칙이다
- 근거: [ADR-004](../adr/ADR-004-simulation-engine.md), D-021, [Q-004 조사](../research/q-004-trading-costs.md), team-design.md 3장
- 담당: sim-engine. 검토: architect, strategy-researcher

## 결정
1. 가상 체결 규칙 `BOOK-V1`: 시장가는 신호 다음 호가 스냅샷을 최우선부터 소진, 지정가는 앞선 잔량 소멸 후 체결, VI·정지 중 체결 없음, 당일 유효(ADR-004 2.2).
2. 주문 지연 기본값 **0.5초** `[가정]`. 체결 모델 ID(`BOOK-V1;latency=PT0.5S`)를 실험 결과에 남기고 같은 ID끼리만 비교한다. 승격 전 0·1.5·2초 민감도(STR-13).
3. 호가 기반 체결에는 D-021 고정 슬리피지 0.15%를 **더하지 않는다**(체결가에 이미 반영). 고정 슬리피지는 호가 없이 체결가만 있는 데이터에만 쓴다.
4. 우리 주문이 먹은 잔량은 다음 호가 스냅샷에 이어지지 않는다 `[가정]`(소액 계좌 전제).
5. 비용 모델은 `autotrade-sim`의 비용 항목 목록으로 두고, 미국 SEC fee·TAF는 거래 기록의 `tax` 열에 넣는다. Q-004 조사 4.4의 `MarketRules`·`BrokerFeeSchedule` 분리 제안은 이번 판에서 채택하지 않는다(ADR-004 3장).
6. 성과 지표 정의는 ADR-004 2.5: 샤프는 무위험 수익률 0·연 252거래일 `[가정]`, CAGR은 실험 달력 일수 기준, 비용 비중은 총비용 / (순손익 + 총비용).
7. Run 시드 파생은 `SHA-256("run-seed-v1|" + randomSeed + "|" + profileHash)` 앞 8바이트.

## 대안 비교
ADR-004 3장. 요약: 지정가 즉시 전량 체결(과대평가로 버림), 호가 체결 + 고정 슬리피지 동시 적용(이중 계산으로 버림), 지표 double 계산(결정론 깨짐으로 버림).

## 위험과 한계
- 0.5초 지연과 소액 전제는 근거가 없다. 단타 성과를 과대평가할 수 있어 민감도 결과를 승격 제안서에 함께 낸다.
- 체결 틱의 주체를 몰라 지정가 대기 체결을 조금 과대평가할 수 있다 `[추론]`.

## 되돌릴 조건
- 6단계 실측(실시간 모의 대 리플레이, 이후 실전 체결 기록)에서 체결 오차가 크면 규칙을 고치고 `RULES_VERSION`을 올린다. 지연 기본값은 실측 p50으로 바꾼다.
