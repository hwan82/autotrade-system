## 결정

1. **판정 기준(Q-056 ①, 계획 9.1 선택지 1)**: LIVE02 선정 조합 계좌(C1~C4)는 D-114 L1~L11의 수치와 계산을 그대로 쓴다. LIVE02에 맞추는 것은 계획 6.1의 세 가지뿐이다.
   - L1 비교 대상은 기준선 `kr-bh-baseline@3`(slots 100)이다.
   - L10 대조군은 같은 선정 묶음 × 무작위 진입(D-126)이고, m은 LIVE02 판정 대상 수(≤ 4)다. 계좌별 문턱은 0.05/m(m = 4면 0.0125), 가족 전체 오류율 5%는 D-114와 같다. 대조군 시드 수는 계획 6.2(N_k)를 따른다.
   - 선정 효과(선정 없는 같은 전략·대조 선정과의 차이)는 리포트 참고 칸이고 판정 항목이 아니다(계획 7.1).
2. **시작 시점(Q-056 ②, 계획 9.1 선택지 1)**: 실험실 실시간 세션은 하나로 둔다. LIVE02는 LIVE01이 끝난 뒤 2026-12-21~2027-02-19(40거래일)에 돈다. 동시 세션 개발은 하지 않고, 녹화 사전 검사는 2026-10-26~12-18 40거래일 전부로 한다. LIVE01 연장이 필요하면 연장이 먼저다(D-128 1번).

## 버린 대안

- ①-2 선정 효과를 판정 항목(L12)으로 추가, ①-3 LIVE02 전용 기준 새 설계: 사용자가 고르지 않음. 이유는 계획 9.1.
- ②-2 동시 세션 개발 후 11월 하순 시작, ②-3 녹화 실험만: 사용자가 고르지 않음. 이유는 계획 9.1·10장.

## 되돌릴 조건

LIVE01이 연장되면 시작일은 연장 끝 다음 거래일로 밀리고 새 번호로 기록한다. 판정 기준을 바꾸려면 등록 파일 커밋(2026-12-18) 전에 새 번호로 사용자 결정을 받는다. 커밋 뒤에는 바꾸지 않는다(D-128 사전 등록).
