# D-143 실전 엔진 시세 전달 설계(7단계 묶음 G: D12, D11 자리, D13 선택지)

- 날짜: 2026-10-26
- 상태: 제안. 아래 결정 1~7은 **추천안 채택(자율)**(지침 8장, data-engineer 추천안). 실전 엔진의 시세 입력과 보호 시세 경로로 넘어가는 조건을 정하므로 실전 관련 PR로 다룬다: architect·risk-ops 검토 → 독립 QA → **사용자 직접 머지**(지침 10장). 머지가 이 기록의 최종 확인이다
- 근거: [ADR-016](../adr/ADR-016-real-engine-market-feed.md), [7단계 준비 계획](../team/stage-7-readiness-plan.md) 2.4장 D11·D12·D13, [ADR-010](../adr/ADR-010-live-feed-and-session.md) 5장·QA [pr-87](../reviews/pr-87/qa.md) R1·R3, [broker-and-fault-design.md](../team/broker-and-fault-design.md) 5.1·6장 #1·#2·#9, D-024, D-059, D-140 ⑥
- 담당: data-engineer(주관), architect(모듈 경계·줄 형식), risk-ops(보호 경로·알림 수준)
- 문서만. 코드·설정 키·녹화 형식은 바꾸지 않는다. 구현은 ADR-016 5장 G0~G5

## 정하지 않은 것

- Q-060(watchlist 구독 상한, D13): 사용자 결정 대기. ADR-016 2.10에 선택지별로 이 설계에 들어가는 방식만 적었다.
- T_quiet(종목별 조용함 기준): 기본값 `market-data.symbol-gap`(장애표 #15, 기본 30초), G0 측정 뒤 risk-ops가 확정, 확정 전 실전 활성화 안 함.
- 첫 실전 구성(게이트웨이 소스 하나)의 장애 테스트 1번 합격 기준: ADR-016 2.11.
- 사용자 PC 게이트웨이 교체 시점: LIVE01 종료(2026-12-18) 뒤가 기본, 그 전이면 6단계 스레드와 맞춰 주말에만.
