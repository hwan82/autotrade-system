## 지적 (막지 않음)

### r1. 새 E3 시험이 바뀐 기준을 행동으로 구분하지 못한다 (권고, EDGE01 실행 전)

- `E3는_본페로니_보정_없이_0_05를_쓴다`는 m = 3, N = 59에서 pNetLow = 1/60을 만든다. 그런데 1/60과 0.05/3은 double로 같은 값이다(`0.016666666666666666`, `1/60 == 0.05/3` 참) `[사실]`(직접 계산). 그래서 옛 식 `pNetLow > alpha`여도 E3는 똑같이 미달이고, 시험이 옛 동작과 새 동작을 가르는 것은 이유 문구 "≤ 0.0500(보정 없음)"과 상수 값뿐이다
- 누가 판정식만 `alpha`로 되돌리고 문구에 `E3_ALPHA`를 남기면 시험이 통과한다 `[추론]`. E3는 EDGE01에서 사실상 실효 기준이므로(앞선 n1) 경계를 행동으로 고정할 가치가 있다
- 추천: pNetLow가 (0.05 ÷ m, 0.05] 사이에 오는 경우를 하나 더 고정한다. 예: N = 59에서 대조군 net 중 1개만 후보 이하가 되게 해 p = 2/60 ≈ 0.033 → E3 미달(옛 식이면 통과)이고, 대조군 2개 이하 조건으로 p = 3/60 = 0.05 → 미달(경계 `>`), 3개면 4/60 → 통과. 판정식만 바뀌는 시험 추가라 EDGE01 결과와 무관하게 언제든 넣을 수 있지만, 실행 전에 넣는 것이 깔끔하다
