# D-026 UI 1차 구현 방식: 빌드 없는 정적 프런트, 실험실 프로세스 웹 서버, 프로필 버전 파일 (Q-006)

- 날짜: 2026-10-08
- 상태: 확정, **추천안 채택(자율)** (project-instructions.md 8장). Q-006 닫음
- 근거와 대안 비교: [ADR-005](../adr/ADR-005-ui-dashboard.md)
- 담당: ui-dev, architect(모듈 경계), risk-ops(설정 화면의 비밀값·실전 키 처리 검토)

## 결정
1. 대시보드 화면은 `autotrade-ui` 모듈의 정적 HTML·CSS·ES 모듈(바닐라 JS)이고, 실험실 프로세스(`autotrade-app-lab`)가 127.0.0.1에서 서빙한다. Node 빌드와 외부 JS·CSS 라이브러리를 쓰지 않는다.
2. 모든 요청은 루프백 Host만 받고, 변경 요청은 CSRF 토큰과 루프백 Origin을 요구한다. CSP는 `'self'`만 허용한다.
3. 전략 프로필은 `strategies/<프로필ID>/v<버전>.yaml` 불변 버전 파일로 저장한다. 편집은 항상 새 버전(새 해시)이며 시장·스타일은 버전 사이에 바꿀 수 없다.
4. 설정 화면은 실시간 변경이 "즉시"인 `lab.*`, `notification.*`만 편집한다. 비밀값은 쓰기 전용이고 화면·응답·로그에 `****`와 설정 여부만 나온다. 증권사 키, 실전 계좌, 시세 소스는 읽기 전용이다.
5. 실전 운영 화면(실전 활성화 2차 확인, PANIC SELL, 블랙리스트 등)은 이 결정 밖이며 별도 PR과 사용자 머지로 다룬다.

## 되돌릴 조건
- 화면이 커져 직접 만든 DOM 도우미로 유지가 어려우면 서버 렌더링(htmx) 또는 경량 SPA로 옮기는 새 결정을 쓴다(REST 계약은 유지).
- 외부 접근·로그인이 필요해지면(D-020 되돌릴 조건) Spring Security로 옮긴다.
