## 결론

**판정: 승인** (막는 항목 없음. 권고 R1·R2, 참고 n1·n2)

판정 기준·결과 값은 바뀌지 않는다. 묶음 실패 처리는 결과를 묶음 순서로 모으므로 결정론이 유지되고, 실패 때는 결과 파일이 없으므로 일부 결과가 판정에 섞일 길이 없다. 주간 점검 5장은 PR #184 R2가 요청한 내용(종목별 중간가 틱 수·거래량 비중, 참고 값, 판정 무관)과 맞고 가상 거래소와 같은 판정 함수를 쓴다. PR #180 n2(L5 판정 불가 + 다른 탈락 → 탈락) 시험도 더해졌다.

## 권고(막지 않음)

- **R1 D-118 이전 기록의 0% 해석.** D-118 이전 입력 기록에는 중간가 틱이 들어가지 않았다(그때는 받기 전에 거절해 기록에 남지 않음, PR #184 검토 S3). 그 날짜를 포함한 주의 5장은 "중간가 0"으로 보이지만 없음의 증거가 아니다. 5장 머리말에 "D-118(BOOK-V6) 이전 기록 날짜는 중간가 틱이 기록되지 않았다" 한 줄, 또는 날짜 범위를 적어 두기를 권한다. LIVE01(2026-10-26~)만 보면 영향이 없다.
- **R2 해석용 합계 행.** 종목별 표 아래 전체 합계 한 줄(체결 틱·중간가 틱·비중)이 있으면 주간 변화 추적과 D-118 `[가정]`(KRX 단독 틱의 반 칸 가격) 실측 근거 정리가 쉽다. 장 구간(시가 단일가 직후·정규장·종가 부근) 분리는 비중이 커질 때만 다음 단계로 둔다.

## 참고
