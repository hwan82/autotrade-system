## 점검표 밖 발견
1. **(수정 필요) 3-R 합격 기준이 원래 Q-018 시험보다 약하고, 두 엔진 공존 상태를 막지 않는다.** `broker-and-fault-design.md:190`, `D-140:18` "두 번째 엔진 기동이 막히거나 첫 엔진이 잠금·소켓 변경을 감지해 긴급 알림". 원래 Q-018 후보(결정 로그 main 159행, ADR-006 199행)는 "두 번째 엔진 기동 차단"이었다. "또는" 분기로 합격하면 두 엔진이 같은 설정 폴더로 함께 도는데, ADR-006 159행 위험 표 그대로 같은 계좌의 Guard가 두 벌이고 화면 명령이 새 엔진으로 간다. 사용자가 새 엔진에서 그 계좌를 활성화하면 두 엔진이 같은 계좌에 주문할 수 있어 중복 주문(A5)·직렬 큐 단일성(A7)이 깨진다. 3-R 합격 기준에 3번의 "중복 주문 0건"이 적용되는지도 표에서 읽히지 않는다. 고칠 것(사용자가 고른 선택지 ①을 바꾸지 않는 risk-ops 조건 추가, ①의 "risk-ops 조건"과 같은 방식):
   - 3-R에도 "중복 주문 0건"을 명시하고, 긴급 알림 분기로 합격하려면 **두 번째 엔진이 어떤 계좌의 주문 세션도 열 수 없음**(활성화·보호 모드 진입 거절, 또는 첫 엔진이 감지 즉시 신규 진입을 멈추고 두 번째 엔진이 기동을 끝내지 못함)을 함께 확인한다.
   - "토스 토큰 무효화 없음"을 "첫 엔진의 증권사 토큰·접속키가 무효화되지 않음(첫 실전 증권사 한국투자 포함, 한국투자 재발급 제한·무효화 여부는 Q-015 실측)"으로 넓힌다. 첫 실전 증권사가 한국투자로 정해졌으므로 지금 문구로는 실제 실전 계좌의 토큰 영향을 시험하지 않는다.
   - 같은 문구를 D-140 ③과 broker-and-fault-design.md 7장 3번 행에 함께 반영하고, 사용자가 머지 때 확인하도록 PR 본문에 "risk-ops 조건 추가"로 적는다.
2. **(수정 필요) D-140 ①의 "어느 단계든 실패하면 PROTECTIVE에 남긴다"가 확인 실패까지 포함하는 것으로 읽힌다.** 지금 구현은 OPEN 계좌에서 "확인 실패·잠김·비밀번호 미설정 PANIC도 OPEN → PROTECTIVE"로 내린다(ADR-006 168행). 이 내리기 규칙을 OFF 계좌에 그대로 옮기면 확인 없이 OFF → PROTECTIVE(주문 세션 열림)로 **올라가** 지침 4장 1번을 약하게 한다. Guard API는 `SecondConfirmation`을 요구해 막고 있지만(`RealTradingGuard.java:210`) 구현 묶음 E가 이 결정 문구를 따르므로 문구로 고정해야 한다. 고칠 것: ①에 "2차 확인이 실패·잠김·비밀번호 미설정이면 OFF 계좌는 OFF 그대로 둔다(올리지 않음). '실패 시 PROTECTIVE 유지'는 확인을 통과해 올린 뒤의 단계(대사·취소·매도) 실패에만 적용"을 넣고, 묶음 E 합격 시험(확인 실패 PANIC에서 OFF 계좌 상태 불변, 주문 세션 허가 발급 불가)을 계획 P7 또는 D-140 후속에 적는다.
3. (권고) 기획서가 단일 원본인데 D-140 후속은 RSK-11·RSK-13만 적고 TST-01(장애 테스트 목록, 기획서 72행 v14.4처럼 하위 항목을 기록해 온 곳)의 3-R 반영을 빠뜨렸다. 후속에 TST-01을 더하기를 권한다.
4. (권고, 구현 묶음 E) ④의 VI 연장 체결 확인 상한(2분 + 30초)과 ⑤의 "서버 측 손절 재설정은 일괄 취소 시각(15:20 `[가정]`) 전에 끝냄"이 겹친다. 15:1x 무렵 VI 종목을 매도 가능으로 판정하면 연장된 상한이 일괄 취소·마감 전 재설정 시각을 넘을 수 있다. ADR-006 207행 "청산 외 주문 금지 구간 시작 전 여유를 둔 시각까지만 매도 가능"의 여유를 VI 연장분만큼 늘리거나, VI 종목은 상한이 그 시각을 넘으면 매도 불가로 보는 규칙과 시험을 P3에 넣을 것.
5. (참고) 계획 2.6 T-R 행 "(Q-018 추가 후보)"와 P4·P5·P7·P8 "사용자 결정 대기"는 결정 전 기준이라고 4.1 머리글(180행)에 밝혀 두었으므로 문제는 아니다. 다음 갱신 때 상태 열을 D-140 기준으로 바꾸면 좋다.
6. (참고) architect 발견 1(Q-060 계산)은 `stage-7-readiness-plan.md:227`에서 ≤ 180 / ≤ 80, D-122 100종목 축소 영향, "실전 몫 먼저 보장" 뜻으로 고쳐졌음을 확인했다. 첫 실전 증권사가 한국투자라 키움 1순위 시세가 유지되는 전제와도 맞다.
7. (참고) 이 PR은 문서만 바꾸지만 실전 영향 결정(D-140)과 장애 테스트 합격 기준을 바꾸므로 지침 10장에 따라 사용자 머지·독립 QA 대상이다. `docs/qa/pending.md`에 요청 행이 있음을 확인했다.
