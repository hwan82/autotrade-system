# D-021 시드머니와 비용 모델 기본값 (D6)

- 날짜: 2026-10-08
- 상태: 확정, **추천안 채택(자율)** (project-instructions.md 8장). 거래세·미국 비용 수치는 `[가정]`이며 Q-004 결과로 갱신
- 근거: team-design.md 8장 D6, team-design.md 2.2 SIM-02(initial-seed-money 1,000만 원), team-design.md 2.3 #8, overseas-design.md 5장(미국 달러 시드 예: 1만 달러)
- 담당: sim-engine(비용 모델 구현), strategy-researcher(Q-004 확인), architect(설정 키)

## 결정
아래 값은 **실험의 기본값**이다. 실험마다 비용 모델은 설정으로 바꿀 수 있고, 비교는 같은 비용 모델끼리만 한다(project-instructions.md 5장).

| 항목 | 국내(KR) 기본값 | 미국(US) 기본값 | 상태 |
|---|---|---|---|
| 시드머니 | 10,000,000 KRW | 10,000 USD | 확정(실험 기본값) |
| 매매 수수료 | 매수·매도 각 0.015% | 매수·매도 각 0.25% | KR: 기존 문서 기본값 유지. US: `[가정]` 국내 증권사 해외주식 온라인 수수료 수준, Q-004로 확인 |
| 증권거래세(농특세 포함, 매도 시) | 코스피 0.20%(거래세 0.05% + 농특세 0.15%), 코스닥 0.20% | 해당 없음 | `[가정]` 2026-01 시행 보도 기준, 공식 법령 확인은 Q-004 |
| 미국 거래 비용(SEC fee, FINRA TAF, 매도 시) | 해당 없음 | 0으로 두지 않고 Q-004 확인 전까지 `[가정]` 0.003% 근사 | `[가정]` |
| 환전 비용 | 해당 없음 | 엔진은 환전하지 않음(D-015). 원화 환산 성과는 참고용 | 확정 |
| 슬리피지 | 0.15% (고정 %) | 0.15% (고정 %) | 확정(기본값). 유동성 기반 모델은 sim-engine이 추가 가능 |

- 거래세 기존 가정 0.18%(team-design.md 2.3 #8)는 2026년 세율과 다르다고 보도되어 위 값으로 바꾼다. 둘 다 공식 확인 전이므로 `[가정]`이다.
- 비용 모델은 이름과 버전(예: `cost-kr-2026-v1`)을 갖고 실험 결과에 기록한다. Q-004로 수치가 바뀌면 새 버전을 만들고, 이전 버전으로 돌린 실험 결과는 지우지 않는다.

## 대안 비교
| 대안 | 장점 | 단점 | 판단 |
|---|---|---|---|
| **A. 기존 문서 기본값 + 세율·미국 비용은 `[가정]` 후 Q-004로 갱신** | 바로 실험 착수 가능, 문서와 일관 | 가정값으로 돈 실험은 비용 모델 버전이 바뀌면 재실행 필요 | **채택** |
| B. Q-004 확인 전까지 비용 모델 확정 보류 | 수치 정확 | 3단계 실험실 MVP 시작이 막힘 | 버림 |
| C. 비용 0으로 시작 | 단순 | "비용 차감 후 성과만 인정"(5장) 위반 | 버림 |

## 위험과 한계
- 수수료 0.015%는 증권사·이벤트마다 다르다 `[추론]`. 실제 사용 계좌 조건으로 Q-004에서 확인한다.
- 슬리피지 0.15% 고정은 저유동 종목에서 과소, 대형주에서 과대일 수 있다 `[추론]`. 3단계에서 호가 기반 체결과 비교해 오차를 측정한다(role-guides.md 8장 시뮬레이션 엔진).
- 미국 수수료·규제 비용은 근사치다. 미국 실험 결과는 Q-004 확인 전까지 리포트에 "비용 가정치 사용"을 표시한다.

## 되돌릴 조건
- Q-004 결과가 위 값과 다르면 새 비용 모델 버전으로 갱신하고 결정 로그에 새 번호로 기록한다(이 결정의 "가정" 칸만 바뀌는 경우는 비용 모델 버전 갱신으로 처리).
- 시드머니를 바꾸려면 비교 가능성이 깨지므로 새 결정으로 기록한다.
