# autotrade-ui

5단계(UI) 작업 자리입니다. 형태는 [D-020](../docs/decisions/D-020-ui-web-dashboard.md): 로컬 웹 대시보드(Spring Boot 백엔드 + 경량 프런트엔드 + SSE).

- 서버는 `127.0.0.1`에만 바인딩한다(같은 PC에서만 접속).
- 실전 관련 버튼은 2차 확인 없이 동작하지 않는다.
- 비밀값은 화면·네트워크 응답·로그에 평문으로 나오지 않는다(`Secret` 타입은 일반 JSON 직렬화로 평문이 나가지 않음).
- 백엔드를 실험실 프로세스에 둘지 별도 모듈로 둘지는 5단계에서 정한다. 실전 엔진 프로세스에는 두지 않는다(ADR-001 2.1).
