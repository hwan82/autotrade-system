## 재무 품질 확인

- 첫 전체 스냅샷 `dart-financials-2026-10-26-da224290`(104,599행)은 **쓰지 않는다**. OpenDART 공시검색이 사업보고서 조건에도 분기·반기보고서를 함께 돌려줘, "값 모름"이 82,049행으로 부풀었다. [PR #250](https://github.com/hwan82/autotrade-system/pull/250)으로 사업보고서(정정 포함)만 남기도록 고친 뒤, 같은 캐시로 이 스냅샷을 다시 만들었다(새 API 호출 0).
- 사업연도별 행 수는 2015~2025년 2,254~3,450이다. 상장사 수와 맞는 규모다 `[추론]`.
- "값 모름" 9,232행, 대체 규칙 대상 묶음 5,194개, 값이 하나도 없는 묶음 1,975개 `[사실]`(리포트). 원인은 2016년 이후 공시를 지금 한꺼번에 받아서다. 뒤에 정정이 나온 공시는 원 공시 값을 받을 수 없다. 대체 규칙은 직전 사업연도로 물러나므로 미래 정보는 쓰지 않는다. 대신 정정 존재를 미리 아는 편향이 남는다(MD-10). 결과 리포트에 재무 선정 조합(`kr-fin-quality-growth@1`)의 대체 규칙 비율과 함께 적는다.
- 계정 응답 대기 0, 접수일 없는 행 0, 자본잠식 54행.

## 등록 당시 열린 항목

- **Q-052 세율 대조**: 코스피·코스닥 2010~2024년 세율은 사용자가 2026-10-18 정리 표(농어촌특별세 포함, 2차 자료)로 비용 표와 다섯 구간 모두 같음을 확인했다. 코넥스 2019-06~2023 칸만 미확인으로 남는다. 4단계 전략 프로필에는 시장 제외 조건이 없으므로, 결과 리포트에 코넥스 종목 거래 건수와 비용 비중을 적는다. 법령 원문 대조 전이라 결론에는 `[가정]`을 붙인다(D-071 7번).
- 승격 전 순서 섞기 재현(D-083 2번)은 결과의 "진입 한도 영향" 표를 보고 판단한다.
