## 결정

1. **판정 범위 이연**: 기획서 14장 5단계 행의 관련 요구사항 중 아래 여섯 항목은 5단계 판정 범위에서 빼고 표의 단계로 넘긴다. 5단계는 [team-design.md](../team/team-design.md) 6장 완료 기준("실험을 UI로 만들고 비교 가능")과 [role-guides.md](../team/role-guides.md) 7장 완료 기준 세 가지(대조표 C1~C4)로 판정한다.

   | 요구사항 | 넘기는 부분 | 담당 | 단계 | 막는 것 |
   |---|---|---|---|---|
   | UI-01 | 실시간 갱신 SSE(지금은 5초 폴링, ADR-006 2.7) | ui-dev | 6단계 시작 전 | 실행기 진행 보고·결과 DB 저장(ADR-005 9장) |
   | UI-02 | 실험 진행 상태(실행은 터미널 명령) | ui-dev, sim-engine | 6단계 시작 전 | 실행기 진행 보고·취소(ADR-004 4장), 결과 DB 저장 |
   | UI-05 | 블랙리스트 관리, 추천 종목·잔고·거래 내역, 모니터링 | ui-dev, risk-ops | 7단계(실전 경로, 사용자 머지) | 실전 엔진 스냅샷의 해당 필드 |
   | UI-07 | 미국 화면(USD, KST·ET 병기, 시장 필터의 미국) | ui-dev | 미국 조합 실험 실행 명령이 생길 때(OVS-09) | 미국 실행 명령, 달러 모의 계좌 |
   | UI-08 | 실전·실시간 모의 계좌 조회 필드와 대사 상태 | ui-dev | 실시간 모의는 6단계, 실전은 7단계 | 실시간 모의 운영, 실전 엔진 스냅샷 |
   | MON-05 | 모니터 에이전트 지표와 모니터링 화면 | ui-dev, risk-ops | 6단계 운영 전(6단계 MON-01~07과 함께) | `autotrade-monitor-agent-jar` 구현 |

2. **완료 기준 해석**: D-074의 해석("화면으로 실험 만들기 = 등록 파일 쓰기, 실행은 사용자가 커밋 뒤 터미널 명령")을 5단계 완료 기준 충족으로 인정한다. 화면 실행 버튼은 D-074 대안 B의 되돌릴 조건(결과 DB 저장과 실행 진행 보고가 생기고 사용자가 원할 때)으로 남는다.
