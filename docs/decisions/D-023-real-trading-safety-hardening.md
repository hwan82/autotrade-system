## 결정

### 공통 원칙
1. 새 차단 규칙은 **신규 진입만** 막는다. 손절·청산·취소는 어떤 차단 규칙으로도 막지 않는다.
2. 자동 해제 없음. 내려갈 때 자동, 다시 열 때는 사람(2차 확인, 감사 로그).
3. 모든 수치는 설정 키 기본값 `[가정]`. 실전 값은 Q-008에서 사용자가 정한다.

### 사용자 선택 4건 (모두 추천안)
| # | 질문 | 결정 | 버린 대안 |
|---|---|---|---|
| 1 | Guard OFF 시 보유 처리 | **보호 모드**: 신규 진입 중단, 미체결 매수 취소, 손절·익절 매도와 서버 측 손절만 계속. 재기동 시에는 자동 진입하지 않고 OFF | 즉시 정지(서버 측 손절 미지원 계좌는 무방비), 전량 청산(실수로 끄면 손실 확정) |
| 2 | 블랙리스트 적용 범위 | **전역**(모든 실전 계좌와 실시간 모의 계좌) | 계좌별(한 종목에 수동 보유와 자동 매매가 겹쳐 노출 초과 가능) |
| 3 | 서킷 3단계 | **자동 청산 없음**, 긴급 알림 후 사용자 PANIC SELL 확인 대기 | 자동 전량 청산(오탐 시 손실 확정) |
| 4 | 국내 PANIC SELL | **시장가**(미국은 지정가+여유폭) | 국내도 지정가+여유폭(급락 중 미체결 잔존) |

## 되돌릴 조건
- 6단계 실측에서 ORD-06 폐기율이나 ORD-08 차단율이 과도하면 값 조정(Q-008, 사용자 결정). 규칙 구조를 바꾸려면 새 결정 번호로 기록.
- Q-002 결과 키움·KIS가 서버 측 손절을 지원하지 않으면, 질문 1·3의 "서버 측 손절이 보호" 전제가 그 계좌에서 성립하지 않는다. 그때 risk-ops가 재기동 직후 보유 보호 방안을 다시 제안한다.

## 남은 위험
- 모든 수치가 원본의 출처 없는 값이다.
- 세션 구간 시각(RSK-11)은 공식 자료 확인 전이다.
