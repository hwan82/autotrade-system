## 점검표 밖 발견
- F1(수정 필요). 기획서 버전 충돌: 이 PR은 `docs/spec/autotrade-spec.md:12`를 v14.13으로 올리고 "v14.12는 다른 열린 PR이 씀"이라 적었는데, 열린 PR #46(`claude/project-thread-vip8tu`, D-058)도 같은 날 v14.13을 쓴다(그 브랜치 `docs/spec/autotrade-spec.md` 변경 이력 첫 줄). PR #38이 v14.12. 둘 중 나중에 머지되는 쪽은 버전과 이력 줄을 고쳐야 한다. 이 PR 쪽에서 v14.14로 옮기거나, PR 본문에 "#46 뒤 머지 시 v14.14로 올림"을 적어 둘 것. D 번호(D-058 #46, D-059 이 PR)는 충돌 없음.
- F2(수정 필요, B7과 연결). D-059 "위험과 한계"에 장애 테스트 1-T 영향을 적고, 처리 방식(예: Client ID 1개인 동안 1-T를 "D-059로 해당 없음"으로 바꾸고 1-0에 "게이트웨이가 토스를 호출하지 않음(호출 계측 0건)" 확인을 넣는 안)을 risk-ops 추천안과 함께 미확정 항목으로 남길 것. 규칙 문구 자체 변경은 사용자 결정 뒤 별도 PR.
- F3(수정 필요, B3과 연결). `docs/config/config-keys.md:15` 근거 칸에 D-059를 더하고 "Client ID가 하나인 동안 게이트웨이는 `TOSS`를 쓰지 않음(구현·경고는 토스 연결 PR)" 한 줄. ADR-003 `:141`, `:166`에 D-059 참조와 "Q-042 ①에서 Client ID 2개 확인 전에는 하지 않음"을 덧붙일 것.
- N1(권고). MD-02 인수 조건 칸(`docs/spec/autotrade-spec.md:118`)은 여전히 "기본 설정 우선순위가 키움·토스·한국투자 테스트"뿐이다. 요구 문장에는 "게이트웨이는 토스를 건너뜀"이 들어갔으니 인수 조건에 "게이트웨이 설정에 `TOSS`가 있어도 토스 호출기를 만들지 않고 경고(D-059, 토스 연결 PR)"를 더하면 추적이 맞는다.
- N2(권고). `docs/team/overseas-design.md` 6장 표(토스 2순위, 72행)와 `docs/decisions/README.md` D-024 행에 D-059 일부 대체 표시가 없다. 결정 로그 원칙(뒤집을 때 새 번호, 옛 결정은 남김)상 필수는 아니나, D-033→D-039 때처럼 옛 문서에 "D-059로 이 범위 보류" 표시를 두면 읽는 사람이 헷갈리지 않는다.
