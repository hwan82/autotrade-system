# 해외주식 거래 구성

작성일: 2026-10-08 · 요청: 해외주식 거래를 위한 구성 추가 · 관련 문서: [broker-and-fault-design.md](broker-and-fault-design.md), [team-design.md](team-design.md)

---

## 1. 결론
- **1단계는 미국주식만** 다룹니다. 3사(토스·키움·한국투자)가 모두 미국주식 API를 제공하는 것으로 확인돼, 국내와 같은 "설정된 곳만, 우선순위대로" 방식을 그대로 쓸 수 있습니다.
- 미국 외 시장(홍콩·중국·일본·베트남)은 **범위에서 제외**합니다(2026-10-08 확정).
- 코드는 **시장(Market) 추상화**를 추가해 국내와 미국이 같은 엔진, 같은 안전 규칙을 공유하고, 시장마다 다른 것(거래 시간, 통화, 호가 단위, 주문 유형, 비용)만 시장별 규칙으로 분리합니다.
- 미국장은 한국 시간 새벽에 열려 **사람이 자는 동안 무인 운영**됩니다. 그래서 해외 실전은 서버 측 보호 주문과 야간 긴급 알림을 필수로 합니다.

## 2. 증권사별 해외주식 지원 (2차 자료, 공식 문서 재확인 필요)

| 항목 | 한국투자 (KIS) | 키움 (REST) | 토스 (Open API) |
|---|---|---|---|
| 미국 시장 | NASDAQ, NYSE, AMEX | 미국주식 카테고리 제공 | 국내(KRX)와 미국 |
| 미국 외 시장 | 홍콩, 중국, 일본, 베트남 거래소 코드 있음 | 확인 안 됨 | 없음 |
| 실시간 시세 | 미국 실시간 무료(0분 지연), 1호가 | 나스닥 토탈뷰 실시간 무료, 10호가 | WebSocket `trade:us`·`orderbook:us`, 프리·정규·애프터·데이마켓 (무료로 추론) |
| 주문 | 지정가, LOO, LOC (매도는 MOO, MOC 추가). **미국 매수 시장가 없음** | 매수, 매도, 정정, 취소 | 지정가, LOC 등. **소수점 수량**, 금액 기준 주문(정규장만) |
| 예약·조건 주문 | 예약주문 API 있음 | 확인 필요 | 조건주문 (OCO, OTO) |
| 모의투자 | 지원 (지정가만, LOO·LOC는 모의 테스트 불가) | 확인 필요 | 확인 안 됨 |
| 환전·통화 | 잔고 조회 시 통화 코드, 원화주문·통합증거금은 계좌 설정에 따름 | 환전 항목 있음 | 환율 조회, 시장별 휴장일·수수료 조회 |
| 기타 | 해외주식 API 사용 동의 별도 필요 | 해외선물·옵션은 별도(OpenAPI-W) | 미국 휴장일 조회(`market-calendar/US`) |

## 3. 시장 추상화

엔진이 시장을 몰라도 되도록 시장별 차이를 `MarketRules`로 묶습니다.

| 규칙 | 국내 (KR) | 미국 (US) |
|---|---|---|
| 통화 | KRW | USD |
| 정규장 (한국 시간) | 09:00~15:30 | 23:30~06:00, 서머타임 중 22:30~05:00 |
| 캘린더 | KRX 휴장일 | NYSE 휴장일, 조기 폐장일, 서머타임 전환일 |
| 가격 단위 | 가격대별 호가 단위 | 0.01달러 (1달러 미만은 더 작은 단위 `[확인 필요]`) |
| 수량 단위 | 1주 | 1주 (소수점은 토스만 가능, 1단계에서는 사용 안 함) |
| 가격 제한 | 상하한가 ±30% | 없음. 대신 종목별 일시 거래정지(LULD) |
| 주문 유형 | 시장가, 지정가 | 증권사별로 다름. KIS는 매수 시장가 없음 → **"지정가 + 허용 여유폭"을 공통 주문 방식으로** 사용 |
| 비용 | 수수료, 거래세 | 수수료, 미국 측 거래 비용(SEC fee 등 `[확인 필요]`), 환전 비용. 양도소득세는 연간 정산이라 거래 비용이 아닌 별도 추정치로 표시 |
| 데이터 | 체결, 호가 | 체결, 호가(제공 범위는 증권사별 확인) |

- 시간 계산은 모두 거래소 현지 시간대(America/New_York)로 하고, 화면 표시만 한국 시간으로 바꿉니다. 서머타임 전환일을 하드코딩하지 않습니다.
- 전략 프로필은 하나의 시장에 묶입니다. 국내 전략을 미국에 그대로 쓰지 않고, 미국용 유니버스·스크리너(최소 주가, 평균 거래대금, 장외시장 제외 등)를 따로 둡니다.

## 4. 계좌와 통화

- 실전 실행 단위를 **(증권사, 시장, 계좌)** 로 확장합니다. 예: `KIS-US-1`, `KIWOOM-KR-1`. 각 단위는 국내와 똑같이 독립 워커, 독립 주문 큐, 독립 킬스위치를 갖습니다.
- 리스크 한도(일일 손실, 종목당 비중 등)는 **계좌 통화로 계산**하고, 화면과 전체 합산은 당시 환율로 원화 환산합니다.
- 환전은 매매 엔진이 하지 않습니다. 1단계는 **미리 달러를 보유한 범위 안에서만 매수**합니다. 매수 가능 금액은 증권사 API로 매번 확인합니다.
- 같은 종목 동시 보유 금지(B3)는 시장 안에서 적용합니다.

---

## 5. 시뮬레이션 실험실 확장
- 모의 계좌에 통화를 추가합니다. 미국 실험은 **달러 시드**로 시작합니다(예: 1만 달러). 국내 실험과 비교할 때는 수익률로 비교하고, 원화 환산 성과는 참고용으로만 씁니다.
- 미국 시세도 국내처럼 녹화하고, 같은 날을 새 전략으로 다시 돌릴 수 있게 합니다.
- 가상 체결도 실전 제약을 그대로 따릅니다. 시장가 매수 없음(KIS 기준 공통 규칙), LULD 정지 중 체결 불가, 정규장 외 체결 안 함.
- 환율 이력을 저장해 원화 환산 성과를 재현할 수 있게 합니다.

## 6. 시세 우선순위 (미국)
| 순위 | 증권사 | 이유 |
|---|---|---|
| 1 | 키움 | 나스닥 토탈뷰 실시간 무료, 10호가 |
| 2 | 토스 | 실시간 WebSocket, 모든 세션 푸시. **D-059 동안 게이트웨이는 건너뜀(아래)** |
| 3 | 한국투자 | 미국 실시간 무료, 1호가, appkey당 41건 |

D-024(D-008 대체)로 확정했습니다. 토스 보유 종목 보호 폴링은 국내와 같이 유지합니다.

**D-059(2026-10-11, 사용자 결정)**: 토스 Client ID가 하나뿐이라 토스 토큰은 실전 엔진만 가지며, 게이트웨이는 토스를 건너뛰어 미국도 키움 → 한국투자 순으로만 받습니다. 토스는 실전 엔진의 보유 종목 보호 폴링에만 씁니다. `[추론]` 토스는 프리·애프터·데이마켓 실시간을 주는데(2장 표), 키움·한국투자의 미국 장외 세션 실시간 지원 여부는 확인하지 않았습니다. 장외 세션 실시간 범위가 줄 수 있어 D-059 위험 칸에 확인 항목으로 둡니다.

미국 실시간 시세 조건은 Q-003으로 확인했습니다([시세 조사](../research/market-data-limits.md) 2장). 키움·한국투자는 무료가 공식 확인됐고 토스는 무료로 추론합니다. 세 곳 모두 미국 통합 시세(NBBO)가 아니라서, 시뮬레이션의 미국 슬리피지 가정은 국내보다 보수적으로 둡니다.

## 7. 야간 무인 운영과 장애 대응 추가

국내 장애 대응표(broker-and-fault-design.md 6장)에 아래를 더합니다.

| # | 장애·위험 | 대응 |
|---|---|---|
| O1 | 사용자가 자는 동안 장애 | Slack 긴급 알림은 방해금지 무시 설정, 일정 시간 확인 없으면 해당 계좌 신규 진입 자동 중단 |
| O2 | PC 절전·윈도우 업데이트 재부팅 | 미국장 시간대에 절전·재부팅 금지 설정을 시작 전 점검 항목으로 확인, 실패 시 해외 실전 활성화 차단 |
| O3 | 서머타임 전환 | 캘린더 기반 계산, 전환 주 첫 거래일에 장 시작 시각 검증 테스트 |
| O4 | LULD 일시 정지 | 해당 종목 신규 주문 금지, 보유분 유지, 정지 해제 후 가격 갭 확인 |
| O5 | 시장가 미지원 주문 거부 | 공통 주문 방식을 지정가 + 여유폭으로 고정, 손절 시 여유폭 확대 규칙 별도 |
| O6 | 달러 잔고 부족 | 매수 전 매수 가능 금액 조회, 부족 시 주문 생략 후 기록 |
| O7 | 조기 폐장일 | 캘린더 반영, 종료 준비 구간을 조기 폐장 기준으로 당김 |
| O8 | PC 장애로 보유 종목 무방비 | 진입 직후 서버 측 보호 주문(토스 OCO/OTO, KIS 예약주문 활용 가능 여부 확인). 보호 수단이 없는 계좌는 해외 실전 활성화 시 경고 |

- 국내 정규장과 미국 정규장은 시간이 겹치지 않아, 같은 4개 프로세스가 시장 세션별로 작업을 바꿔 돌립니다. 미국 주간거래(한국 낮 시간)는 국내장과 겹치므로 1단계 범위에서 제외합니다.

## 8. 팀 역할 영향
| 역할 | 추가 책임 |
|---|---|
| 기획 리드 | 해외 요구사항(OVS-xx) 관리, 시장 범위 결정 기록 |
