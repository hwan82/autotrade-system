# 미국주식 현황 점검과 추천 종목 발굴 방안 제안

작성일: 2026-10-10 · 역할: 전략 연구(기획 리드 관점 포함) · 요청: 미국주식 모의·실전 기능 여부, 별도 구성 필요 여부, 월가 리포트·유명 투자자 보유 종목 기반 종목 발굴 방안
관련: [overseas-design.md](../team/overseas-design.md), [기획서 12장 OVS](../spec/autotrade-spec.md), [D-041](../decisions/D-041-selection-x-signal-combinations.md), [결정 로그](../decisions/README.md)

> 이 문서는 시스템 설계 제안이며 투자 자문이 아니다. 특정 종목의 매수·매도를 권하지 않는다. 실전 적용 여부는 사용자가 결정한다(지침 7장).

---

## 0. 결론

1. **미국주식은 "설계와 규칙 일부"까지 있고, 모의·실전 모두 아직 돌릴 수 없다.** 모의(실험실)는 미국 시세 수신·녹화, 환율 이력, 미국 유니버스·전략 프로필이 비어 있다. 실전은 국내도 7단계 전이라 주문 연동이 없다(2장).
2. **별도 시스템(별도 엔진)으로 나누는 것은 추천하지 않는다.** 지침 4장 9번과 OVS-02가 "같은 엔진·같은 안전 규칙, 차이는 `MarketRules`로만"을 정했고, 실전 계좌는 이미 (증권사, 시장, 계좌) 단위로 독립 워커·주문 큐·킬스위치를 갖는다. 대신 **운영 단위로는 미국을 따로 구성**한다: 미국 전용 모의 계좌(달러 시드), 미국 전용 선정·전략 프로필, 미국 화면 필터, 야간 무인 운영 규칙(3장). 사용자 결정 필요(Q-043).
3. **종목 발굴은 "선정 프로필"(D-041, STR-15)의 새 조건 종류로 넣는다.** 13F(버핏 등 기관 분기 보유), ARK 일간 보유 내역, Form 4(내부자 매수)는 SEC·ARK가 무료로 공개한다. 이 신호로 후보를 고르고, 기존 매매지표와 조합해 같은 기간·시드·비용으로 비교 검증한다(4~6장).
4. **월가 애널리스트 리포트 원문은 쓸 수 없고, 의견·목표가 이력은 대부분 유료다.** 과거 시점 값(PIT)이 없는 무료 스냅샷으로는 백테스트가 미래 정보 오염이라 검증 수단이 없다. 과금이므로 사용자 결정(Q-044).
5. **가장 큰 위험은 "지금 유명한 투자자를 고른 것" 자체가 생존편향이라는 점과, 13F의 최대 45일 지연이다.** 투자자 명단은 그 시점 데이터로 정한 규칙 명단과 함께 돌리고, 신호 시각은 분기 말이 아니라 **EDGAR 접수 시각**으로 한다(7장).
6. **버핏·우드 외 추천 명단(4.6)**: 가치·집중 7곳(버크셔, 히말라야, 퍼싱스퀘어, 바우포스트, 에이크리, 파브라이, 펀드스미스), 성장·기술 4곳(ARK, 타이거, 코투, 론파인), 매크로·회전 비교군 4곳(듀케인, 아팔루사, 바이킹, 서드포인트). 더 빠른 신호로 13D(5영업일)를 2차 확장 후보로 둔다.
7. **LLM으로 보고서를 "전문가처럼 판독"하는 방안은 과거 백테스트에 쓸 수 없다.** 모델이 이미 그 이후를 학습했기 때문이다. 판독 결과를 날짜별 스냅샷으로 고정해 앞으로의 실시간 모의로만 검증한다(4.5).

## 3. "독립된 별도 구성"이 필요한가

사용자 의견: "독립적으로 별도 구성이 되어야 할 것 같다." 무엇을 독립시키느냐에 따라 답이 다르다.

| 안 | 내용 | 장점 | 단점 | 판단 |
|---|---|---|---|---|
| **A. 같은 엔진 + 미국 전용 운영 구성** (추천) | 엔진·리스크 체인·주문 상태머신·블랙리스트는 공통. 미국은 별도 실행 단위(`KIS-US-1` 등), 별도 달러 모의 계좌, 미국 전용 선정·전략 프로필, 미국 화면 필터, 야간 운영 규칙 | 안전 규칙이 한 벌이라 검증된 코드를 그대로 씀(지침 5장 "같은 코드"). 국내 장애 테스트 결과를 재사용. 확정 결정 유지 | 미국 전용 데이터 수집은 여전히 새로 만들어야 함 | 채택 |
| B. 미국 전용 엔진(별도 코드) | 미국만의 엔진·리스크 코드 | 국내 변경이 미국에 영향 없음 | 안전 코드가 두 벌이 되어 한쪽만 고쳐지는 사고 위험. 장애 테스트 8종을 두 번. 지침 4장 9번·OVS-02와 충돌 | 버림 |
| C. 같은 코드, 미국 전용 실전 엔진 프로세스(5번째 프로세스) | A에 더해 미국 실전 엔진만 따로 띄움 | 미국 장애가 국내 실전 프로세스에 닿지 않음 | 국내·미국 정규장이 겹치지 않아(overseas-design.md 7장) 이득이 작고, D-013 4프로세스 구조 변경 | 지금은 버림. 미국 주간거래를 넣거나 두 시장 실전이 동시에 돌 때 다시 검토 |

**독립성은 이미 계좌 단위로 보장된다.** 실전 계좌는 (증권사, 시장, 계좌)마다 독립 워커·큐·킬스위치를 갖고(OVS-05), 실전 계좌끼리 영향을 주지 않는다(지침 4장 6번). 리스크 한도는 계좌 통화(USD)로 계산한다. 그래서 A안은 "시장별로 따로 운용·비교·켜고 끄기"라는 사용자 의도를 엔진을 둘로 나누지 않고 충족한다고 본다 `[추론]`.

되돌릴 조건: 미국 쪽에서만 필요한 안전 규칙이 `MarketRules`로 표현되지 않아 엔진에 시장 분기가 생겨야 할 때, 또는 두 시장 실전이 같은 시간대에 동시에 돌게 될 때 C안을 다시 검토한다.

## 4. 추천 종목 발굴 신호 후보

모든 신호는 **선정 프로필의 조건**(STR-15·16)으로 들어가 "후보 목록"을 만든다. 실제 매수 시점·수량·청산은 기존처럼 전략 프로필(매매지표)이 정하고, 실험 계좌 하나 = (선정 프로필, 전략 프로필) 조합 하나로 비교한다(D-041). 13F처럼 분기 단위로 바뀌는 신호는 **중기(`POSITION`, 20~120거래일)** 스타일에 맞는다(D-043).

### 4.1 13F 기관 보유 (버핏·버크셔 등)

| 항목 | 내용 |
|---|---|
| 무엇 | 운용 재량 자산 1억 달러 이상 기관이 분기마다 제출하는 미국 상장 주식 보유 내역 |
| 출처·비용 | SEC EDGAR, 무료. 접근 한도 초당 10건, 요청 헤더에 사용자 식별(User-Agent) 선언 요청 [사실](SEC "Accessing EDGAR Data") |
| 시점 | 분기 말 후 **45일 이내** 제출 [사실](investor.gov Form 13F). 분기 말 기준 보유라 제출 시점엔 최대 45일 이상 낡은 정보 |
| 한계 | 롱 포지션 중심(공매도·현금·해외 주식 미포함) `[추론]`, 비밀 처리 요청으로 일부 종목이 늦게 공개될 수 있음 `[가정]`, 종목이 CUSIP으로만 적혀 티커 매핑 필요 |
| 신호 예 | ① 신규 편입 ② 비중 확대 ③ 포트폴리오 내 최대 비중(고확신) 종목 ④ 여러 기관 동시 신규 편입(합의) |
| 선행 연구 | 공개 보유 복제 펀드("copycat")가 비용 차감 후 원 펀드와 통계적으로 구별되지 않는 성과 [사실](Frank·Poterba·Shackelford·Shoven 2004, NBER w8653. 1990년대 고비용 펀드 표본이라 일반화 한계). 펀드 매니저의 최고 확신 종목이 초과 성과를 냈다는 연구(Cohen·Polk·Silli "Best Ideas") `[가정]`(원문 미확인), 버크셔 공개 후 복제도 초과 성과(Martin·Puthenpurackal 2008) `[가정]`(2차 자료만 확인) |

### 4.4 월가 애널리스트 의견·목표가

| 항목 | 내용 |
|---|---|
| 리포트 원문 | 증권사 고객 전용이고 재배포 제한. **수집 대상이 아님** |
| 의견·목표가 데이터 | 과거 시점 이력(PIT)이 있는 데이터는 유료 공급자(예: I/B/E/S, FactSet, Zacks 등) `[가정]`. 무료 API는 대체로 현재 스냅샷이나 짧은 이력이라 백테스트에 미래 정보가 섞임 `[추론]` |
| 선행 연구 | 합의 의견 상위 종목 포트폴리오의 초과 수익은 잦은 교체 비용을 빼면 신뢰성 있게 남지 않는다는 결과(Barber·Lehavy·McNichols·Trueman 2001) `[가정]`(초록 2차 자료만 확인) |
| 판단 | 과금 항목이라 사용자 결정 전에는 쓰지 않는다(Q-044). 쓰더라도 신호 시각은 "의견 발표 시각"이어야 한다 |

### 4.5 LLM 판독 (10-K·실적 발표·공개 리포트 요약을 "전문가처럼" 읽기)

| 항목 | 내용 |
|---|---|
| 장점 | 사용자 요청인 "전문가 수준 판독"에 가장 가까움. 13F·ARK 후보의 사업 내용·위험 요인을 사람이 읽기 쉽게 정리 |
| 치명적 한계 | 모델은 학습 시점까지의 미래를 이미 안다. 과거 문서를 지금 판독하면 **미래 정보가 섞인 백테스트**가 된다(지침 5장 위반). 또 같은 입력에도 출력이 달라질 수 있어 결정론이 깨진다 |
| 쓰는 방법 | ① 판독 결과를 날짜·모델·프롬프트 버전과 함께 **스냅샷 파일로 고정**하고(D-019 Python 수집기와 같은 경계), 실험은 스냅샷만 읽는다 ② **앞으로의 실시간 모의로만** 성과를 검증한다 ③ 처음에는 점수에 넣지 않고 사람이 보는 설명 자료로만 쓴다 |
| 판단 | 2차 단계. 1차는 4.1~4.3 공시 신호만으로 규칙 기반 선정을 검증한다 |

**명단을 실험에 쓰는 방식**
- FIXED 명단 v1 = A 7곳 + B 4곳(버크셔·ARK 포함 11곳). C 4곳은 별도 비교 계좌.
- 신호는 4.1의 ①~④(신규 편입, 비중 확대, 상위 비중, 여러 곳 동시 편입). "여러 곳 동시 편입"은 같은 묶음 안에서 센다(가치와 성장이 같은 종목을 사는 것은 성격이 다른 신호라서).
- 명단을 바꾸면 선정 프로필 버전이 바뀌고(STR-15), 새 조합으로 처음부터 검증한다(D-045).

## 5. 선정 프로필 설계 예시 (미국, 중기)

아래는 형식 예시다. 수치는 실험으로 정할 `[가정]` 파라미터이고 추천 종목이 아니다.

```yaml
# selections/us-13f-conviction/v1.yaml (예시)
market: US
style: POSITION
signal_time: edgar_accepted_date    # 분기 말이 아니라 EDGAR 접수일, 그 다음 거래일부터 사용
managers:
  mode: RULE                        # RULE(그 시점 데이터로 고른 명단) | FIXED(사용자가 정한 명단)
  rule: { min_years_filing: 10, max_positions: 40 }   # 집중 투자형 기관
conditions:
  - holding_rank_top: 5             # 각 기관 포트폴리오 비중 상위 5
  - change: [NEW, INCREASE]         # 신규 편입·비중 확대
  - min_managers: 2                 # 2곳 이상 합의
gates:                              # STR-10 미국판 하드 필터
  min_price_usd: 5
  min_avg_dollar_volume_20d: 20000000
  exclude: [OTC, ADR_OPTIONAL, ETF]
valid_until: next_13f_season        # 다음 분기 제출 시즌 전까지 후보 유지
```

함께 돌릴 비교 묶음(같은 기간·시드·비용 모델):

| 계좌 | 선정 | 목적 |
|---|---|---|
| 1 | 13F 고확신·합의, 명단 RULE | 주 가설 |
| 2 | 13F 같은 조건, 명단 FIXED v1의 A묶음(가치·집중 7곳) | 유명 투자자 명단의 효과와 사후 선택 편향 크기 비교(4.6) |
| 2b | 같은 조건, FIXED v1의 B묶음(성장·기술 4곳) | 성향별 차이 |
| 2c | 같은 조건, C묶음(매크로·회전 4곳) | 13F 지연 피해가 큰 성향인지 확인하는 대조 |
| 3 | ARK 연속 매수 | ARK 신호 단독(보관 시작 이후 기간만) |
| 4 | 13F + Form 4 내부자 매수 동시 충족 | 신호 결합 효과 |
| 5 | 같은 유니버스 무작위 선정(같은 교체 주기·종목 수) | 대조군(STR-17) |
| 6 | SPY 매수 후 보유 | 기준선 |
| 진단 | 13F를 **분기 말 기준**으로 넣은 버전 | 미래 정보 버전. 성과로 쓰지 않고 "45일 지연으로 잃는 몫"만 측정 |

## 6. 검증 방법

1. **시점 고정**: 신호는 공시 접수일(거래소 현지 날짜, America/New_York) **다음 거래일부터** 선정에 쓴다(MD-10, ADR-007 `apply_from` 직전 거래일까지의 데이터). 장전·장중·장 마감 뒤·휴장일 접수 모두 같은 규칙이고, ARK 파일은 파일에 적힌 날짜(다음 거래일 표기)가 아니라 수집한 현지 날짜를 공개일로 본다. 정정 제출(13F-HR/A)은 정정 접수일 다음 거래일부터 반영한다(D-042 재무 값 원칙과 같음). 장전에 접수된 13F를 같은 날 쓰면 실전(전날 밤 선정 고정)에서는 쓸 수 없는 신호가 시뮬레이션에만 들어가 성과가 부풀기 때문이다(PR #38 architect 검토 1번).
2. **생존편향 제거**: 상장폐지 종목을 포함한 당시 미국 유니버스와 일봉이 필요하다. 무료 증권사 API는 현재 상장 종목 위주라 이 조건을 못 채운다 `[추론]`. 그래서 과거 백테스트는 유료 데이터가 필요하거나(Q-044), 무료로는 지금부터의 실시간 모의로만 검증한다.
3. **투자자 선택 편향**: "지금 유명한" 버핏·우드를 고른 것은 그들이 과거에 잘했기 때문이다. 그 명단으로 과거를 돌리면 좋게 나오는 게 당연하다. 그래서 명단은 그 시점 데이터로 정한 RULE 명단을 주 가설로 하고, FIXED 명단은 비교용으로만 둔다.
4. **선발 기준**: STR-04 그대로(비용 차감 후, 최소 거래 수, 표본 외 성과가 학습 구간의 60% 이상, 파라미터 ±20% 민감도). 중기 스타일은 다년 일봉 워크포워드로 선발하고, 8주 실시간 모의는 무결성·괴리 확인용(D-043).
5. **다중 비교 보정**: 조합 목록을 실험 전에 등록하고(STR-17) 대조군 20회 분포와 비교한다(D-027).
6. **표본 수 위험**: 13F는 1년에 4번만 바뀐다. 5년 백테스트라도 리밸런싱 20회 남짓이라 우연과 구별하기 어렵다 `[추론]`. 신호 결과를 "확정된 기법"이 아니라 "후보 풀을 좁히는 필터"로 보는 것이 안전하다.

## 7. 위험과 한계

| 위험 | 영향 | 대응 |
|---|---|---|
| 13F 지연(최대 45일+) | 기관이 이미 팔았을 수 있음 | 진단 버전으로 지연 손실을 측정하고, 단타·스윙에는 쓰지 않고 중기만 |

| Q-045 | 미국 공시 신호 선정을 범위에 넣을까 (D-041 5장 "미국 재무 조건 선정은 범위 밖" 확장, 지침 8장 5번) | ① 13F·ARK·Form 4 무료 공시 신호만 포함 / ② ①+LLM 판독(앞으로 검증만, 점수 제외) / ③ 지금은 넣지 않음 | **②** (LLM은 설명 자료로만) |

가에서 유료 공급자 가격은 조사하지 않았다(과금 결정 뒤 data-engineer가 공식 요금표로 확인).
